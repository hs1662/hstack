# 머지 전 실제 호스트 세션 점검

패키지의 `--strict` 검증은 스킬·훅·MCP의 배치를 검사한다. 로그인한 세션의 도구 권한이나 작업자 디스패치까지 증명하지는 않는다. 다음 점검은 Agy와 Claude Code에서 각각 독립된 임시 로컬 저장소와 새 Run으로 수행한다.

| 확인할 동작 | 세션에서 남길 증거 |
|---|---|
| 스킬과 MCP 발견 | 그래프 스킬, 기존 핸드오프·프리플라이트 스킬, `verify_completion`과 `manage_handoff`가 함께 보인다. |
| 호스트 선택 | `host-caps`가 Agy에서는 `invoke_subagent`, Claude Code에서는 `Agent`를 힌트로 표시한다. 세션에서 실제로 허용되지 않은 도구를 사용할 수 있다고 간주하지 않는다. |
| 읽기 작업 하나의 왕복 | `ready`에서 나온 노드를 `claim`하고, 호스트에서 실제 읽기 작업자를 호출한다. 호출을 확인한 뒤에만 실제 핸들을 `start`에 기록한다. 작업자에게 엔진 비밀이 들어 있는 지시서 파일 자체를 넘기지 않는다. |
| 증거 판정 | 같은 소스 파일을 작업자와 검증기가 독립적으로 확인한다. 올바른 행 범위는 검증하고, 존재하지 않는 행을 인용한 별도 시도는 반려한다. 워커의 완료 선언만으로 승인하지 않는다. |
| 인계와 재개 | 카나리아 경고가 난 세션에서 불변 스냅샷 ID와 소유자 핀을 확인한다. 새 세션에서 그 ID로 복원하고, 폐기된 시도의 `settle`은 코드 `49`로 거절되는지 확인한다. |
| 종료와 비용 | 일부 필수 샤드를 빼고 축약한 결과는 `partial`이어야 한다. 전부 수락한 Run과 비교해 누락 의무·실패 증거가 보존됐는지 확인한다. 호스트 사용량을 받지 않았다면 `metrics`의 토큰과 비용은 `null`이어야 한다. |
| 기존 훅과 v2 절단선 | 기존 완료·언어 훅이 계속 동작하고, 병렬 쓰기나 `integrate`는 `ERR_V2_WRITE_INTEGRATION_NOT_ENABLED`로 거절돼야 한다. |

호스트 이름·버전, Run ID, `graphRev`·`epoch`, 비밀이 없는 CLI 응답, 호스트 호출 기록과 검증 영수증을 한 묶음으로 보관한다. 실제 디스패치 권한이 없어 실행하지 못한 항목은 통과가 아니라 **미확인**으로 남긴다.
